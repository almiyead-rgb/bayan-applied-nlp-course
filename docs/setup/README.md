## قاعدة الدورة

إذا نجح CPU فأنت جاهز. GPU يسرّع بعض الخطوات لكنه ليس شرطًا للاجتياز.

## المواقع التي نحتاج اختبارها

- [GitHub](https://github.com)
- [Google Colab](https://colab.research.google.com)
- [Google Drive](https://drive.google.com)
- [PyPI](https://pypi.org)
- [Hugging Face](https://huggingface.co)

إذا كانت شبكة الجهة تمنع أحدها، أبلغ المدربة قبل الدورة ولا تحاول تجاوز سياسة الشبكة.

## لا تثبت شيئًا محليًا إلا إذا

- اخترت ذلك بنفسك كمسار إضافي؛
- تعرف كيفية إدارة Python environments؛
- وتفهم أن الدعم داخل الدورة يركز على Colab.

المسار المحلي ليس أسرع بالضرورة، وقد يختلف عن بيئة بقية الصف.

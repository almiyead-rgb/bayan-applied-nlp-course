## قاعدة الاستشهاد العلمي

صفحات الأيام ستربط إلى الوثائق الرسمية للمكتبات أو الورقة العلمية الأصلية عند شرح claim تقني. المدونة أو الفيديو قد يساعدان في التوضيح، لكنهما لا يحلان محل المصدر الأولي عند إثبات حقيقة أو رقم.

كل رقم داخل المشروع يحمل أحد الوسوم:

- `REFERENCE`: مصدر منشور ورابط.
- `MEASURED`: ناتج تشغيل موثق.
- `TARGET`: حد نجاح تدريبي.
- `EXAMPLE`: رقم توضيحي فقط.

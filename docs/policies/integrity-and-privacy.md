# النزاهة والخصوصية | Integrity and Privacy

## المبدأ

المشروع عام؛ لذلك كل ما ترفعه يمكن أن يراه الآخرون. استخدم بيانات تعليمية اصطناعية أو عامة موثقة فقط.

## ممنوع رفعه

- أسماء أو أرقام هوية أو هواتف أو بريد لأشخاص حقيقيين.
- شكاوى أو مراسلات أو سجلات حقيقية.
- password أو API token أو cookie أو recovery code.
- ملف `.env` أو credentials JSON.
- روابط Drive تكشف ملفات خاصة.
- أوزان نماذج كبيرة أو بيانات لا يسمح ترخيصها بالنشر.
- screenshots تحتوي شريط حسابك أو بيانات شخصية.

إذا رُفع secret بالخطأ، حذفه في commit جديد لا يكفي لأنه يبقى في التاريخ. أوقف العمل، ألغ المفتاح من مزوده، وأبلغ المدربة فورًا.

## البيانات المسموحة

- بيانات بيان الاصطناعية الموزعة مع الدورة.
- بيانات عامة ذات مصدر وترخيص واضحين.
- عينة صغيرة مصطنعة أنشأتها للاختبار.
- outputs محدودة لا تعيد كشف نص حساس.

## نسخة العرض ونسخة المعالجة

احتفظ بمتغيرين مختلفين:

- `display_text`: النص الأصلي للعرض، إذا كان آمنًا.
- `model_text`: نسخة masking/normalisation للنموذج.

لا تطبع النص قبل masking في logs العامة.

## النزاهة الأكاديمية

### مسموح

- قراءة الوثائق والمراجع.
- مناقشة المفهوم مع زميل.
- استخدام المكتبات المفتوحة وفق ترخيصها.
- طلب تفسير خطأ.
- الاستفادة من مساعدة خارجية مع توثيقها وفهم ما تقدمه.

### غير مسموح

- نسخ مستودع متدرب آخر أو تسليمه باسمك.
- نسخ نتائج رقمية مرجعية على أنها `MEASURED`.
- تغيير الاختبارات لإخفاء فشل الكود.
- استخدام frozen test لاتخاذ قرارات tuning.
- اختلاق metric أو benchmark لم يُشغّل.
- إخفاء مصدر كود جوهري.
- مشاركة ملفات التقييم أو حلولها.

## توثيق المساعدة والمصادر

في `DECISIONS.md` أو قسم Acknowledgements اذكر المصدر عندما يؤثر في قرار أو كود:

```text
Source:
What was used:
What I changed:
How I verified it:
```

لا يلزم توثيق كل استدعاء Python عادي؛ المطلوب توثيق التأثير الجوهري.

## فحص الخصوصية قبل كل Commit

- [ ] بحثت عن `token` و`password` و`secret` و`email`.
- [ ] راجعت outputs داخل notebooks.
- [ ] راجعت screenshots.
- [ ] البيانات مصطنعة/عامة ومرخصة.
- [ ] لا أوزان أو ملفات ضخمة.
- [ ] `.gitignore` موجود.
- [ ] أستطيع شرح مصدر كل ملف.

## الإبلاغ

عند الشك لا تنشر. احتفظ بالملف خارج GitHub، وأرسل وصف المشكلة دون مشاركة السر أو البيانات نفسها.

# النزاهة والخصوصية | Integrity and privacy

## القاعدة الواضحة | The clear rule

| English | العربية |
|---|---|
| **Using the supplied starter as a scaffold is allowed. Submitting the instructor's unchanged notebook, copied outputs or another learner's work as your own is not.** Saving a copy in Drive is the starting step, not the completed assignment. | **استخدام حزمة البداية هيكلًا للعمل مسموح. تسليم دفتر المدربة دون عمل شخصي، أو نسخ نتائجها أو مشروع زميل ونسبته إليك، غير مسموح.** حفظ نسخة في Drive خطوة البداية، وليس إنجاز المشروع. |
| You must run your own copy, complete the required work, document your decisions and measured extension, and explain your results. Renaming files, changing colours or adding your name does not establish independent work. | يجب تشغيل نسختك وإكمال العمل المطلوب وتوثيق قراراتك والامتداد المقاس وشرح نتائجك. تغيير الاسم أو الألوان أو إضافة اسمك لا يثبت مساهمة مستقلة. |
| Submissions are subject to comparison with the starter and other submissions, review of outputs and Git history, and individual questions or a small change-and-explain check. | تخضع التسليمات للمقارنة بحزمة البداية والتسليمات الأخرى، ومراجعة المخرجات وتاريخ Git، وأسئلة فردية أو فحص تغيير صغير مع تفسيره. |
| Similarity is an indicator, not a verdict: shared starter code is expected. A checker or AI detector cannot guarantee detection of all misconduct or prove it from a percentage alone. Findings require evidence and an opportunity to explain authorship. | التشابه مؤشر وليس حكمًا: تشابه كود البداية متوقع. لا يضمن فاحص أو كاشف ذكاء اصطناعي اكتشاف كل مخالفة أو إثباتها بنسبة وحدها. يستلزم الحكم دليلًا وفرصة لتوضيح مصدر العمل. |
| Copied or unverified evidence earns no credit for the affected requirement. An established academic-integrity violation prevents completion under the stated policy; concerns are reviewed before a final decision. | لا يمنح الدليل المنسوخ أو غير المتحقق نقاط المتطلب المتأثر. تمنع مخالفة النزاهة المثبتة الإكمال وفق السياسة المعلنة؛ وتراجع الملاحظات قبل القرار النهائي. |

## المصادر وأدوات المساعدة | Sources and assistance

اكتب في README قسم **My contribution / مساهمتي**: التغيير، ومسار الملف، وسبب القرار، والدليل الناتج. ثم قسم **AI assistance / الاستعانة بالأدوات**: الأداة إن استُخدمت، ونوع المساعدة، وكيف راجعت الناتج. اكتب «لم أستخدم أدوات مساعدة» عندما يكون ذلك صحيحًا. الإفصاح لا يعفيك من فهم الكود، ولا يمنح نقاطًا إضافية لاستخدام أداة.

In README, identify your change, file, reason and evidence under **My contribution**. Under **AI assistance**, disclose the tool, assistance and verification—or honestly state none. Disclosure does not replace understanding and using a tool earns no extra points. Cite external code, datasets and models and preserve their licences.

## ما لا يُنشر | Do not publish

| English | العربية |
|---|---|
| No real beneficiary data, national IDs, personal phone/email, API keys, passwords or private Drive shares. Use synthetic course data and a GitHub username or learner ID in public files. | لا بيانات مستفيدين حقيقية أو هويات أو هواتف أو بريد شخصي أو مفاتيح API أو كلمات مرور أو مشاركات Drive خاصة. استخدم بيانات الدورة الاصطناعية واسم GitHub أو معرّف المتدرب في الملفات العامة. |
| Model weights, ONNX files and caches stay outside the public submission. Record source, version/hash and reproduction steps instead. | تبقى أوزان النماذج وملفات ONNX والذاكرة المؤقتة خارج التسليم العام؛ ويوثق المصدر والإصدار والبصمة وطريقة إعادة الإنتاج. |
| If a credential is exposed, revoke it immediately and notify the instructor privately. Deleting the visible line alone may leave it in Git history. | إذا انكشف مفتاح فألغِه فورًا وأبلغ المدربة بصورة خاصة؛ حذف السطر الظاهر وحده قد يبقيه في تاريخ Git. |

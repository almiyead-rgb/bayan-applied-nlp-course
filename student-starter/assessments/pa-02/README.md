# PA‑2 — مراجعة تقرير تقييم منافس
# Evaluation Report Review

**نوع النشاط:** ممارسة فردية دون درجة مستقلة في التقييم النهائي.

اقرأ [تقرير الفريق المنافس](rival-team-report.md)، ثم اكتب مراجعتك في [القالب](PA2_REVIEW_TEMPLATE.md). لا تعِد حساب أرقام غير متاحة ولا تخترع فاصل ثقة؛ المطلوب فرز ما يمكن قبوله، وما يمنع الشحن، وما يحتاج قياسًا جديدًا.

## مخرجات الممارسة

- `PA2_REVIEW.md` مكتمل.
- قرار صريح: `SHIP` أو `CONDITIONAL` أو `BLOCK` مع شروط قابلة للتحقق.
- commit hash ورابط الملف العام.

## مؤشرات جودة المحاولة التدريبية

| البعد | التركيز التدريبي | الدليل المتوقع |
|---|---:|---|
| صحة الفرز | 50% | يميز blocker عن limitation وعن معلومة ناقصة |
| قابلية الإجراء | 30% | كل finding يحدد مالكًا ودليل إغلاق |
| الاستدلال الإحصائي | أساسي | يرفض الادعاءات التي لا تسندها split/CI/slices |

لا توجد إجابة منشورة في المستودع العام. يقيم المقيم جودة الاستدلال وربطه بالأدلة، لا مطابقة صياغة حرفية.
